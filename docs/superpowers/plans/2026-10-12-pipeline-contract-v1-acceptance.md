## Migration and release notes

- `vxf_0009` extends `vxf_0008`, advances plugin schema/worker compatibility to epoch/build 8, and adds only plugin-prefixed tables.
- Downgrade refuses when any desired configuration, snapshot, outbox, or package-delivery rows exist. The safe recovery is a consistent database/plugin/artifact snapshot restore, not a destructive downgrade.
- This branch is a protocol/schema foundation, not an integrated production pipeline. All gates marked NOT TESTED or BLOCKED above remain open.

### Remaining interoperability limit

KitsuSync v1 permits template `overrides`, but the shared contract does not state how those values map to Plugin-owned nested template nodes. This implementation rejects non-empty overrides instead of silently ignoring them. The Plugin's current local SharedTemplateConfiguration remains the folder-tree authority; only selected default catalog IDs/revisions and scopes are resolved. A real KitsuSync-to-Plugin sync rehearsal must validate catalog selection, parent scope behavior, and database/worker execution before this is accepted for UAT.

### Provider boundaries and human UAT gates

- Google account credentials are never returned to KitsuSync or browser APIs. The KitsuSync authorization response carries only the OAuth redirect URL/intent result. Callback URL query strings must be redacted by the reverse proxy and tracing stack.
- KitsuSync remains the source of desired configuration and activation. Preview may run while inactive; explicit Apply and its Worker job require active current config/epoch and current permission/root fences.
- Minimal isolated UAT prerequisites: (1) owner-approved Google OAuth app and supported least-privilege root-selection flow, (2) separately protected encryption key directory mounted only to API/Worker and a registered exact callback, (3) disposable pinned PostgreSQL/Zou runtime using the committed source, (4) synthetic isolated My Drive/Shared Drive root for real-provider acceptance. Production and real Drive were not accessed in this development pass.
