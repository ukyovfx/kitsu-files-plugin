# Isolated host environment

`host-lock.yaml` records immutable Kitsu/Zou source refs and the official combined Docker test image. The image is disposable and local-only; Docker creates anonymous container-owned PostgreSQL and preview volumes for its declared data directories. No user-named volumes, Production data, or external credentials are attached. Runtime behavior is not supported for Production until the remaining plugin upgrade, migration rollback, worker and provider gates pass against this exact image.

The image was pulled locally by digest and started with Docker's automatic anonymous volumes. Its Zou CLI package reports `1.0.94`, its Python runtime is `3.10.12`, and the unauthenticated `/api` readiness response returned HTTP 200. Kitsu's official browser embeds Production plugins as same-origin iframes; the plugin menu flag is `frontend_project_enabled`.

The plugin package was installed in a fresh copy of the same disposable image. Zou applied additive plugin revisions `vxf_0001` and `vxf_0002`, creating plugin-owned `plugin_vfx_files_*` tables and loading `/plugins/vfx_files/*`; the Kitsu-facing same-origin proxy prepends `/api`. The Files feature gate defaults off. Against the pinned Zou test app, cookie-authenticated health and CSRF-token requests pass; cookie-only mutation and cross-origin mutation fail, and same-origin mutation with a short-lived identity-bound CSRF token passes. The current host-backed PostgreSQL/API suite passes 55 tests with synthetic rows, including upload routes, staging, idempotent finalize, persisted job assertions, Postgres folder-binding recovery with FakeStorage, concurrent publish numbering, worker transfer evidence, ambiguous provider response reconciliation and process-crash recovery. These results do not prove Production compatibility.

The frontend build runs on Node 24.14.0 / npm 11.11.0 with pinned Vue/Vite and Playwright dependencies in `frontend/package-lock.json`. It builds to `plugin/frontend/dist` for Zou's official static plugin route. The minimal `fetch` wrapper sends same-origin cookies without reading them and obtains a short-lived plugin CSRF token before mutations. Vitest covers client behavior; headless Playwright drives isolated browser interactions with deterministic API failure fixtures. The three-test browser suite passes: two fixture workflows plus one live test. The live test loads the installed static page at its canonical trailing-slash URL, uploads to the pinned Zou API/PostgreSQL, invokes the separate worker against disk-backed FakeStorage, refreshes and asserts completed persisted metadata. Worker process-crash recovery and ambiguous-provider-response cases pass in the pinned-host suite. Browser interruption/resume remains fixture-only; Google Drive, Production compatibility, migration rollback and restore rehearsal remain unverified. The current official Kitsu release checked on 2026-10-11 is `v1.0.70`; the highest official Zou tag checked in the CGWire repository is `v1.0.94`. The disposable host matches this pair and the exercised upload slice passes there. No official Kitsu/Zou pair-compatibility guarantee was found, and VFX Studio's Production versions remain unknown. Compatibility does not extend beyond the isolated install, plugin migration and upload paths exercised here.
