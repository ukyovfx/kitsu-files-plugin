# Isolated host environment

`host-lock.yaml` records immutable Kitsu/Zou source refs and the official combined Docker test image. The image is disposable and local-only; Docker creates anonymous container-owned PostgreSQL and preview volumes for its declared data directories. No user-named volumes, Production data, or external credentials are attached. Runtime behavior is not supported for Production until the remaining plugin upgrade, migration rollback, worker and provider gates pass against this exact image.

The image was pulled locally by digest and started with Docker's automatic anonymous volumes. Its Zou CLI package reports `1.0.94`, its Python runtime is `3.10.12`, and the unauthenticated `/api` readiness response returned HTTP 200. Kitsu's official browser embeds Production plugins as same-origin iframes; the plugin menu flag is `frontend_project_enabled`.

The plugin package was installed in a fresh copy of the same disposable image. Zou applied additive plugin revisions `vxf_0001` through `vxf_0005`, creating plugin-owned `plugin_vfx_files_*` tables and loading `/plugins/vfx_files/*`; the Kitsu-facing same-origin proxy prepends `/api`. The Files feature gate defaults off. Against the pinned Zou test app, cookie-authenticated health and CSRF-token requests pass; cookie-only mutation and cross-origin mutation fail, and same-origin mutation with a short-lived identity-bound CSRF token passes. The current host-backed PostgreSQL/API suite passes 89 tests with synthetic rows. Coverage includes upload routes, staging, idempotent finalize, persisted jobs, folder discovery and provisioning, Working revision conflict and authorization, concurrent HTTP reservations, Postgres folder-binding recovery, FakeStorage worker transfer, ambiguous provider-response reconciliation and process-crash recovery. These results do not prove Production compatibility.

The frontend build runs on Node 24.14.0 / npm 11.11.0 with pinned Vue/Vite and Playwright dependencies in `frontend/package-lock.json`. It builds to `plugin/frontend/dist` for Zou's official static plugin route. The minimal `fetch` wrapper sends same-origin cookies without reading them and obtains a short-lived plugin CSRF token before mutations. Vitest passes 11 tests. The fixture Playwright suite passes three tests; the two live tests skip when their disposable-host credentials are not supplied. Separately, `files-installed-page.e2e.pw.js` passed against the installed Files page on the pinned host: a synthetic Manager selected and activated a nested template, submitted a Task provisioning request, and a separate worker persisted FakeStorage bindings; after refresh, the page rendered valid folder links. Artist A then uploaded w001, Artist B downloaded and verified it, uploaded w002, and refreshed UI displayed both downloadable revisions with Latest Working at w002. The one-file provider process-crash and ambiguous-success recovery cases pass in pinned-host tests; interrupted multi-file transfer recovery remains untested. The current official Kitsu release checked on 2026-10-11 is `v1.0.70`; the highest official Zou tag checked in the CGWire repository is `v1.0.94`. The disposable host matches this pair. No official Kitsu/Zou pair-compatibility guarantee was found, and VFX Studio's Production versions remain unknown. Live Drive, Production compatibility, full Publish/QC/Approval/Handoff integration, migration restore and backup/restore rehearsal remain unverified. Compatibility claims are limited to the isolated install and explicitly exercised plugin paths on this image.
