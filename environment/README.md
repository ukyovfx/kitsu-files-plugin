# Isolated host environment

`host-lock.yaml` records immutable Kitsu/Zou source refs and the official combined Docker test image. The image is disposable and local-only; Docker creates anonymous container-owned PostgreSQL and preview volumes for its declared data directories. No user-named volumes, Production data, or external credentials are attached. Runtime behavior is not supported for Production until the remaining plugin upgrade, migration rollback, worker and provider gates pass against this exact image.

The image was pulled locally by digest and started with Docker's automatic anonymous volumes. Its Zou CLI package reports `1.0.94`, its Python runtime is `3.10.12`, and the unauthenticated `/api` readiness response returned HTTP 200. Kitsu's official browser embeds Production plugins as same-origin iframes; the plugin menu flag is `frontend_project_enabled`.

The plugin package was installed in a fresh copy of the same disposable image. Zou applied revision `vxf_0001`, created 16 `plugin_vfx_files_*` tables, and loaded `/plugins/vfx_files/*`; the Kitsu-facing same-origin proxy prepends `/api`. The Files feature gate defaults off. Against the pinned Zou test app, cookie-authenticated health and CSRF-token requests pass; cookie-only mutation and cross-origin mutation fail, and same-origin mutation with a short-lived identity-bound CSRF token passes. The current host-backed PostgreSQL/API suite passes 51 tests with synthetic rows, including actual upload routes, staging, idempotent finalize, persisted job assertions, Postgres folder-binding recovery with FakeStorage, and concurrent publish numbering. It does not prove Production compatibility.

The frontend build runs on Node 24.14.0 / npm 11.11.0 with pinned Vue/Vite and Playwright dependencies in `frontend/package-lock.json`. It builds to `plugin/frontend/dist` for Zou's official static plugin route. The minimal `fetch` wrapper sends same-origin cookies without reading them and obtains a short-lived plugin CSRF token before mutations. Vitest covers client behavior; headless Playwright drives isolated browser interactions with deterministic API failure fixtures. Those browser tests are UI-level evidence and are not a substitute for the separate pinned-host/PostgreSQL integration suite. The current browser suite covers resumable upload interaction and handoff response/pointer display; complete browser-to-worker flows remain pending.
